# **App Name**: Chaitanya Aggarwal

## Core Features:

- Experience Timeline: Interactive timeline displaying professional experience with smooth scrolling.
- Project Spotlights: Detailed project descriptions accessible through animated transitions.
- Skills Matrix: Skills showcase with progress bars and short descriptions, offering insight into product management proficiencies.
- Contact Hub: Contact section with interactive form and links to professional profiles.
- Resume Download: Downloadable resume in PDF format.
- Landing Page: Landing page with a profile picture and a brief summary, linked to full details with an animated transition.
- PM Toolbox: A PM Toolbox section listing tools and when/how they are used. Example: “Jira – Used to manage 20+ release cycles. Customized sprint velocity tracking with burndown insights.”

## Style Guidelines:

- A deep blue (#34495E) evokes trust and reliability, crucial in product management.
- A light gray (#ECF0F1), close to white, creates a clean, professional backdrop that keeps focus on the content.
- A vibrant teal (#1ABC9C) provides highlights and draws attention to interactive elements.
- Font: 'Inter', a grotesque-style sans-serif for its modern and objective feel.
- Use flat, minimalist icons to represent different skills and project categories. Use lucide-react (lightweight open-source icon set used in shadcn/ui) for clean SVGs.
- A single-page layout with distinct sections, each transitioning smoothly upon scrolling. Include sticky navbar or scrollspy to help navigate long sections.
- Subtle parallax scrolling effects and micro-interactions to enhance engagement without overwhelming the user. Inspired by Netflix's interface, prioritize fluid transitions, hover feedback, and scroll inertia. Use Framer Motion.
